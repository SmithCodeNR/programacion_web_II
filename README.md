# RoadSafe

## Descripción del problema

RoadSafe es una aplicación web desarrollada para permitir que los ciudadanos reporten huecos en las vías de manera rápida y sencilla. La plataforma busca mejorar la movilidad urbana, reducir accidentes y facilitar que las autoridades prioricen las reparaciones según los reportes recibidos.

## Tecnologías utilizadas

- JavaScript
- HTML5
